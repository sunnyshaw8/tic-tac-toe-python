# Tic Tac Toe 🎮

My first Python project — a Tic Tac Toe game built from scratch.

## Features

- Two-player can play this game sitting on the same computer
- Player marker selection
- Random first player
- Position validation
- Win detection
- Replay option

## What I used

- Python
- Jupyter Notebook

## What I learned

- Functions
- While loops
- If/else conditions
- Lists
- User input
- Random module
